# СКОЛ — сайт строительного бренда

Статический адаптивный сайт СКОЛ на HTML, CSS и vanilla JavaScript — без сборки и серверных зависимостей.

## Файлы
- `index.html` — структура и содержание сайта.
- `styles.css` — фирменная система, анимации и адаптивные стили.
- `script.js` — мобильное меню, появление блоков при прокрутке и обработка формы обращения.

## Фирменная система
- Графитовый: `#25282B`
- Тёплый белый: `#F5F3EE`
- Терракотовый: `#C96B45`
- Винный акцент: `#6B2737`

## Локальный запуск
Откройте `index.html` в браузере. Для разработки можно использовать любой локальный статический сервер.

## Размещение
Проект подходит для собственного веб-хостинга с поддержкой статических файлов, GitHub Pages или другого статического хостинга. Для собственного домена потребуется настроить DNS у регистратора и HTTPS на стороне хостинга.

## Перед публичным запуском
1. Заменить референсные архитектурные изображения на лицензированные изображения или фотографии реальных объектов.
2. Подключить серверную обработку формы: текущая версия открывает почтовую программу и не сохраняет заявки на сервере.
3. Подготовить юридическую информацию и политику обработки персональных данных под выбранный способ приёма заявок.
4. Проверить сайт в реальных браузерах и на мобильных устройствах.
5. Проверить юридическую доступность названия СКОЛ.

## Важно
Изображения сейчас используются как визуальные референсы, а не как подтверждение выполненных проектов СКОЛ. Не выдавайте их за портфолио компании.
